# Flipkart field mapping

Supported keys are `key_chain`, `pendant_locket`, `bangle_bracelet_armlet`, `earring`, `jewellery_set`, `necklace_chain`, and `car_hanging_ornament`. Renderer category order is followed by Net Quantity, Dimensions, MRP, and Generic Name.

Canonical case-insensitive catalog extras flow into immutable snapshots. Flipkart v2 keeps raster human-readable text plus native TSPL barcode. Logical font key `mms_default_sans` resolves to Docker DejaVu Sans; diagnostics record family, key, SHA-256 fingerprint, and sizes. Missing fonts fail; fingerprint changes invalidate approval.
