# Phase 3.1 production gate

Phase 3.1 hardens the software boundary before any TSC TE244 approval. It adds canonical catalog-to-snapshot field resolution, Amazon renderer v2, reproducible Flipkart fonts, local authentication/RBAC, server-derived barcode checks, exact approval identity, and normalized printer state.

CI green is not renderer approval. Real transport remains disabled, no profile is auto-approved, and physical validation remains mandatory.
