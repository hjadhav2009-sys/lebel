# MMS Web phase plan

Phase 1 established the catalog/import web foundation. Phase 1.5 hardened identity, synchronization, security, and CI. Phase 2 added account-scoped Amazon/Flipkart consignments, validation, immutable preparation, and exact snapshot reprints.

Phase 3 adds bounded indexed consignment matching, production renderers and previews, immutable artifact storage, versioned profile approval, barcode verification, paired Windows agents, RAW spooler delivery, lease-based duplicate protection, diagnostics, Windows packaging, and Print Queue/Printers UI. Real transport remains disabled by default and requires physical TSC TE244 validation.

Phase 4 may add Packing Tool 1 and PDF Tool 3 adapters after parity work. They are intentionally unchanged in Phase 3.
# Current gate

Phase 3.1 production hardening precedes TSC TE244 calibration. Phase 4 (Packing Tool 1 and PDF Tool 3) must not begin until physical printer/profile approval and controlled transport validation are complete.
